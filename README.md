## 一、最快上手（不注册任何账号）

双击打开 `index.html` 就能用（数据存在本机浏览器里，各设备互相独立）。

## 二、完整功能：云同步（腾讯云）

### 第 1 步：注册腾讯云并创建云开发环境（约 15 分钟）

1. 打开 <https://cloud.tencent.com>，用微信扫码或邮箱注册，并完成**实名认证**（国内手机号 + 身份证，按提示操作即可）。
2. 进入 <https://console.cloud.tencent.com/tcb>（云开发 CloudBase 控制台），点「新建环境」：
   - 环境名称随便填（如 `yunqi`）
   - 计费方式选**按量付费**（有免费额度；新用户可开通免费体验版环境，见文末常见问题）
3. 创建成功后，在环境列表里**复制环境 ID**（形如 `yunqi-1a2b3c4d`）。

### 第 2 步：创建数据库集合

1. 左侧菜单进入你刚创建的环境 → **数据库** → 集合管理。
2. 新建 4 个集合：`weights`、`events`、`suggestions`、`settings`（空集合即可，不需要手动加字段）。
3. 对**每个集合**：点「权限设置」→「自定义安全规则」，粘贴：

```json
{ "read": true, "write": false }
```

（含义：所有人可读、客户端不可直接写；写入全部走云函数校验。）

### 第 3 步：创建云函数 app_write

1. 环境里左侧菜单 → **云函数** → 新建云函数。
2. 函数名称填 **`app_write`**，运行环境选 **Nodejs 16.13**（或更新版本），创建方式选「空白函数」。
3. 把本项目的 `cloudbase/app_write.js` 内容**全部粘贴**进去（替换默认代码），保存并部署。
4. 云函数里默认已内置 `@cloudbase/node-sdk`；如提示找不到依赖，在云函数编辑器里安装依赖 `@cloudbase/node-sdk` 再部署。

### 第 4 步：把环境 ID 填进 config.js

用记事本打开 `js/config.js`，把环境 ID 填进去：

```js
CLOUDBASE_ENV: 'yunqi-1a2b3c4d',   // 你的环境 ID
```

保存后重新打开 index.html，设置页「云同步状态」显示 **云同步·腾讯云（已连接）** 即成功。电脑上记一条体重 → 手机打开同一页面刷新，能看到同一条数据，就说明云同步通了。

### 第 5 步：发布到 GitHub Pages（生成分享链接）

**方式 A：网页上传（最简单，不需要装任何工具）**

1. 注册/登录 <https://github.com>（如还没有账号）。
2. 右上角 **+** → **New repository**，仓库名 `pregnancy-calendar`，选 **Public**，点 Create repository。
3. 点 **uploading an existing file**，把本项目全部文件（index.html、css 文件夹、js 文件夹、cloudbase 文件夹、README.md、.nojekyll）**按原目录结构**拖进去，点 Commit changes。
4. 仓库页面 → **Settings** → 左侧 **Pages** → Source 选 **Deploy from a branch**，分支 **main**，目录 **/ (root)** → Save。
5. 等 1-2 分钟，页面顶部出现网址：`https://你的用户名.github.io/pregnancy-calendar/`——这就是分享给亲友的链接，微信里可以直接打开。

**方式 B：命令行（适合以后频繁更新）**

```bash
cd pregnancy-calendar
git init && git add -A && git commit -m "init"
git remote add origin https://github.com/你的用户名/pregnancy-calendar.git   # 先在网页建好空仓库
git branch -M main && git push -u origin main
# 再到仓库 Settings → Pages 开启（同方式 A 第 4 步）
```

### 第 6 步：微信里打开验证

手机微信打开链接：登录页点「亲友」应直接进入，能看到日历和详情；提一条建议；再用「咕嘟」身份（密码 leyuan）登录，应能看到建议、记录体重。

## 三、日常使用

- **改代码后微信不更新**：微信缓存很顽固。每次更新后，把 `index.html` 里所有 `?v=1` 改成 `?v=2`、`?v=3`…再上传；微信里点右上角「刷新」。
- **备份**：咕嘟登录后，设置页 →「导出备份（JSON）」，建议每月导一次。恢复时用「导入备份」。
- **改咕嘟密码**（两处都要改）：
  1. 设置页 → 密码哈希生成器 → 输入新密码得到哈希；
  2. 更新 `js/config.js` 里 `owner.hash`；
  3. 云函数控制台更新 `app_write.js` 里的 `OWNER_HASH`，重新部署。
- **修改末次月经**：咕嘟登录 → 设置页 → 基础信息。全站孕周、产检提醒自动重算。
- **云同步断连**：显示「当前离线，显示的是最近一次缓存数据」一般是网络问题；持续失败请检查 config.js 的环境 ID。

## 四、常见问题

**Q：腾讯云免费吗？会不会扣费？**
云开发按量付费有免费额度，家庭每天几十次读写远用不完。另外新用户可开通「免费体验版环境」（3000 点/月），注意它**每 6 个月需手动续期**，到期记得续；若环境被停，数据可能不可用，建议每月导出一次 JSON 备份。

**Q：数据存在哪里？安全吗？**
网页文件在 GitHub（公开仓库），数据在腾讯云数据库。数据库安全规则：所有人可读、客户端不可直接写；唯一写入口是云函数，云函数只认咕嘟的密码哈希。亲友免密是设计如此（拿到链接即能看），请控制链接传播范围。

**Q：亲友能改数据吗？**
不能。亲友界面没有任何编辑入口；就算绕过界面直接调云函数，也会被云端拒绝（仅咕嘟哈希有效）。

**Q：体重图为什么没有推荐区间带？**
咕嘟在设置页填「身高」和「孕前体重」后，系统按 WS/T 801-2022 自动计算 BMI 分类和推荐增重区间。

**Q：42 周之后、LMP 之前的日期为什么点不了？**
日历浏览范围固定为末次月经前 30 天到孕 42 周，超出范围显示为灰色。

**Q：腾讯云 SDK（cloudbase.full.js）加载失败怎么办？**
它是腾讯官方 CDN（static.cloudbase.net），国内一般稳定；偶尔加载失败时，页面会自动退化为本地缓存数据，刷新重试即可。
