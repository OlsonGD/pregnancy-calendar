## 一、最快上手（不注册任何账号）

双击打开 `index.html` 就能用（数据存在本机浏览器里，各设备互相独立）。

## 二、完整功能：云同步（Supabase 免费版，无需信用卡）

### 第 1 步：注册并创建项目（约 10 分钟）

1. 打开 <https://supabase.com>，点 **Start your project** 用邮箱注册并登录
2. 点 **New project**：
   - Name：随便填（如 `yunqi`）
   - Database Password：自己设一个强密码（**记下来，以后可能用到**）
   - Region：选 **Southeast Asia (Singapore)**（离国内最近）
3. 点 **Create new project**，等 1-2 分钟初始化完成

### 第 2 步：建表（一次性）

1. 左侧菜单点 **SQL Editor** → **New query**
2. 把本项目 `supabase-setup.sql` 的**全部内容**粘贴进去
3. 点右下角 **Run**（或按 Ctrl+Enter），看到 **Success. No rows returned** 即成功

### 第 3 步：把密钥填进 config.js

1. 左侧菜单 **Project Settings**（齿轮图标）→ **API**
2. 复制两个值：
   - **Project URL**（形如 `https://abcdefgh.supabase.co`）
   - **anon public** 那串密钥（很长）
3. 用记事本打开 `js/config.js`，填进去：

```js
SUPABASE_URL: 'https://abcdefgh.supabase.co',
SUPABASE_ANON_KEY: '你的 anon public 密钥',
```

> ⚠️ 只能填 **anon public**。**绝对不要填 service_role 密钥**（那个能绕过所有权限）。

4. 再把 `index.html` 里所有 `?v=2` 改成 `?v=3`（强制刷新缓存），然后重新上传部署

设置页「云同步状态」显示 **云同步（已连接）** 即成功。

### 第 4 步：重新发布网页

把改好的 `js/config.js` 和 `index.html` 重新上传到 GitHub 仓库（网页拖拽覆盖，或用下方命令行）。

**命令行方式（推荐，以后更新更快）**

```bash
cd pregnancy-calendar
git add -A && git commit -m "启用云同步"
git push
```

## 三、日常使用

- **改代码后微信不更新**：微信缓存很顽固。每次更新后把 `index.html` 里的 `?v=` 数字加一，重新上传；微信里点右上角「刷新」。
- **备份**：咕嘟登录后，设置页 →「导出备份（JSON）」，建议每月导一次。恢复用「导入备份」。
- **改咕嘟密码**（两处都要改）：
  1. 设置页 → 密码哈希生成器 → 输入新密码，复制得到的哈希；
  2. 更新 `js/config.js` 里 `owner.hash`，重新部署；
  3. Supabase → SQL Editor 执行：
     ```sql
     create or replace function app_write(p_key text, p_op text, p_table text, p_data jsonb)
     returns jsonb language plpgsql security definer set search_path = public as $$
     -- ……（把 supabase-setup.sql 里第 3 节的函数整体重新粘贴一遍，
     --      只改开头的 v_owner_hash 为新哈希）……
     $$;
     ```
     最简单的方式：直接重新执行一遍改过哈希的 `supabase-setup.sql`（脚本可重复执行）。
- **修改末次月经**：咕嘟登录 → 设置页 → 基础信息。全站孕周、产检提醒自动重算。
- **云同步断连**：显示「当前离线，显示的是最近一次缓存数据」一般是网络问题，刷新重试即可。

## 四、常见问题

**Q：Supabase 免费吗？会不会突然收费？**
免费版永久免费、无需信用卡（500MB 数据库，家庭记录体重绰绰有余）。唯一注意点：项目 **7 天没有任何访问会被自动暂停**，每天打开页面就是访问，正常使用不会触发；若被暂停，到 Supabase 后台点 Restore 即可，数据不丢。

**Q：数据存在哪里？安全吗？**
网页文件在 GitHub（公开仓库），数据在 Supabase 云数据库。数据库开启了行级安全：**所有人可读，但任何人都不能直接写入**——唯一写入口是 `app_write` 函数，函数内部校验咕嘟的密码哈希。亲友免密是设计如此（拿到链接即能看），请控制链接传播范围。密码哈希在前端源码里可见，属于「防误操作」级别而非防攻击级别——家庭使用够用。

**Q：亲友能改数据吗？**
不能。亲友界面没有任何编辑入口；就算绕过界面直接调用云端函数，也会被拒绝（只有咕嘟的哈希有效）。

**Q：体重图为什么没有推荐区间带？**
咕嘟在设置页填「身高」和「孕前体重」后，系统按 WS/T 801-2022 自动计算 BMI 分类和推荐增重区间。

**Q：42 周之后、LMP 之前的日期为什么点不了？**
日历浏览范围固定为末次月经前 30 天到孕 42 周，超出范围显示为灰色。
