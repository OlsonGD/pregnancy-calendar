数据库安全规则（每个集合都设这一条）
====================================

在腾讯云开发控制台 → 数据库 → 选择集合 → 权限设置 → 自定义安全规则，
粘贴下面这段，保存。

四个集合（weights / events / suggestions / settings）全部相同：

{
  "read": true,
  "write": false
}

含义：
- read: true   → 任何人（匿名）可读，对应「亲友免密查看」
- write: false → 任何客户端都不能直接写库；
                 所有写入都走云函数 app_write（云函数以管理员身份执行，
                 不受此规则限制），由云函数校验咕嘟的密码哈希。

也可以在控制台的权限预设里选「所有用户可读，仅管理端可写」，
效果与此相同。
